本版合併四條功能線與兩份使用手冊內容，行為依 SPEC §§94–100、D127–D136；測試檔最高編號為 `m96.test.ts`。

- `feat/codex-session-48`：Codex session 唯讀 parser、Reference Set、loopback API 與頁面；對應 §§98–99、D130–D134，聚焦 `m94`–`m95`。

本次 release commit 只更新 `package.json`、`package-lock.json` 與文件，不修改 `src/`、`test/`；既有 LocalDocSearch 資料目錄、`LOCALDOCSEARCH_DATA_DIR`、IPC／MCP／`docsearch` 相容入口維持不變。

## 已完成

- 文件庫以獨立 `library.sqlite` 保存路徑、stable reference、名稱、事件時間與已存搜尋條件，不保存正文、snippet、passage、對話或 AI 輸出。
- Codex parser 只在本機唯讀 `sessions/` 下的 `rollout-*.jsonl`，輸出受界定的 session metadata 與 Reference Set；不公開 conversation content、tool result 或附件內容。
- 工作台與 Codex 頁共用目前 Workbench token session 的索引文件上下文集合；只接受已索引、stable reference 與 canonical path 相符的文件，總選取上限仍為 20 份，Workbench 關閉後狀態消失。
- `docs/USER-GUIDE.md` 已修正為可從 Codex 頁加入／移出上下文，並說明跨頁保留與低信心 reference 不提供該操作。
