# 0.39.0 交接：區段儲存、不記位置索引與提前停止

更新：2026-09-28。package 為 **0.39.0**。

## 範圍

- 行為權威：SPEC §52；決策：D083；研究：`../research/index-size-2026-09-28/RESULTS.md`；驗證：`../0.39.0-VALIDATION.md`。
- 原文改存為每份文件約 64K 字元的 zstd 區段（`document_chunks`），段落位置用偏移表；只有無法推算的段落存 `block_meta`。
- 內容索引改為區段級、不記位置的 trigram 與 1／2 字 token（`search_chunk_*`，FTS5 `detail=none`）；檔名、標題索引不變。
- 搜尋改為依排序延遲產生的結果串流：檔名／標題命中由小索引算出，內文命中依排序走訪候選區段、即時正規化驗證，夠用即停。結果內搜尋改為疊在上一層上的過濾。搜尋語意與結果不變。
- 總筆數：預設快速（驗證到 500 份，超過回報下限）；工作台設定、CLI `search --exact-total`、MCP `exactTotal` 可改為精確。
- 舊 index（0.38 或更早）由寫入程序自動遷移成區段儲存，完成後刪除所有舊結構，空白頁過半時自動 `VACUUM`；新增 `compact` 命令。
- search trace schema 5。
