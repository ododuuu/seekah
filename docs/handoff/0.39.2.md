# 0.39.2 交接：局部更新分批穩定確認

更新：2026-09-28。package 為 **0.39.2**。

## 範圍

- 行為權威：SPEC §54；決策：D085；驗證：`../0.39.2-VALIDATION.md`。
- 起因：使用者新建 `Desktop\測試用.md` 搜尋不到，因為排在 Codex 解開的約 2,840 個 plugin 檔案之後，每個檔案各等 1.5 s 穩定觀察，約 70 分鐘。
- 修正：
  1. 每輪最多 500 筆或約 5 s；輪與輪之間釋放 writer lock、立即接續。
  2. 整批先觀察、只等一次防抖時間、再觀察；相同者寫入。§46.6 的兩次觀察保證不變。
  3. 仍在變動的檔案延後到下一輪，不原地退避（原本每檔最多約 53 s）；連續 5 次後記為不穩定並保留既有索引。
- 不改 schema、status 欄位或背景校正。
