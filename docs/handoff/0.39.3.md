# 0.39.3 交接：忽略資料夾的修改事件、局部更新輪替

更新：2026-09-28。package 為 **0.39.3**。

## 範圍

- 行為權威：SPEC §55（並修正 §54.1 的處理時間起算點）；決策：D086；驗證：`../0.39.3-VALIDATION.md`。
- 起因：0.39.2 重啟後超過 5 分鐘停在 `.grok`（666 檔、499 MB）的子樹掃描。
- 修正：
  1. 資料夾 `change` 事件在內容已被監看時忽略（Windows 實測：資料夾內的變動另有逐檔事件）；`rename`（新增、移入、改名）仍掃描子樹。
  2. 局部更新輪替：先處理本圈未處理過的待辦，避免持續改寫的檔案一直排在最前面。
  3. 每輪 5 s 處理上限改從穩定等待之後起算。
- 否決：同一圈內新進的先處理（湧入期間處理量崩落）。
