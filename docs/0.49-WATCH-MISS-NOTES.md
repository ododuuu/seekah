## m103 `autoupdate diagnose`

`test/m103.test.ts` 覆蓋：

- synthetic `LiveStatus` 的 32 筆 timing、p50／p95／max、`--limit 1..32` 上限與錯誤碼計數。
- 根目錄與 degraded child 只輸出雜湊、深度、計數與時間；合成根路徑、檔案內容、degraded reason、instance id 均不得出現在摘要。
- 沒有 daemon 時 `autoupdate diagnose` 回傳 `AUTOUPDATE_NOT_RUNNING` 且不建立狀態檔；`--limit 33` 回傳 `AUTOUPDATE_DIAGNOSE_LIMIT_INVALID`。
- 隔離 synthetic daemon 啟動後新增文件，先由 `search()` 證明事件已可搜尋，再執行 diagnose；daemon 停止與暫存資料清除均在測試 `finally` 完成。

診斷命令只讀 live control snapshot，不啟動、停止或重啟 daemon；一般 `autoupdate status` 的完整路徑輸出契約未放寬。

反向驗證：暫時把 diagnose formatter 的根目錄雜湊改成完整路徑後，m103 兩個隱私斷言均失敗（`REVERSE_PRIVACY_EXIT=1`）；已復原實作，復原後 m103 兩項均通過。
