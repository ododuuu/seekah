# LocalDocSearch 使用導向路線圖

更新：2026-09-25。以自己每天用得順為成功標準，作品集／在職碩為加值，星數不是目標。

目前程式基線與 package：**0.36.2**。0.37.0 的 GUI 加入根目錄、日常局部更新、持久 queue、有界 watcher scopes、可接續分批校正、普通使用者登入啟動與 mixed all-terms pruning 已實作；只剩公司 Windows／真實 Host 人工驗收。沒有 0.38.0。本版起以版本號作唯一里程碑名稱，不再新增 M 編號。

## 目標與界線

使用者回報約 378 GB、358,102 檔案，一次完整同步約 2 小時 21 分，索引 1113.18 MiB 可接受。0.30.0 已補 java／sql／js、Big5、容量與錯誤可觀測性；0.31.0 已將背景更新改為局部事件處理並以定期完整校正補遺漏。PDF／PPTX 真實錯誤依 `COMPANY-WINDOWS-DIAGNOSTICS.md` 在公司電腦調查，不立即新增瘦身工具或 OCR。

只索引自己有權限的目錄，靠內文找到文件並打開使用。目前以使用者的 macOS 電腦持續迭代，維持 Node.js 22.17.0 以上、可攜 CLI、純本機，並保留 Windows 相容方向。與檔名工具互補，不做全碟檔名引擎或文件管理系統。

預設不做 OCR、自動向量 RAG 或整庫灌入模型。0.33.0 已依使用者決定加入本機 MCP；它只暴露唯讀、有界工具，不改變公司內容是否可交給特定 AI 的政策判斷。掃描件若成為主痛，OCR 另規劃為預設關閉的選配。公司內容不外傳，不繞過權限。

## 格式擴充停損

現有盤點用於排序，不代表所有文件都有業務價值，也不是 2.83 GB 工作負載的分布。0.9.0 先交付 VSD v11 直接文字後，等待真實失敗代碼及使用頻率，再決定是否投資較舊 VSD、master／動態欄位或下一種格式。格式未覆蓋不阻止規劃找檔閉環；不因參考專案列了功能就追齊。

不新增讀取全機內容的盤點工具。需要再盤點時沿用 Windows 命令，只統計副檔名數量；無權限位置跳過。2.83 GB 首次索引約一分鐘是使用者觀察，不能外推 200 GB 或新版效能。

## 未來 AI 上下文模式

A：使用者自行搜尋，再選取結果送入上下文。B：使用者觸發並輸入關鍵字／問題，搜尋後仍由使用者選取並確認。0.34.0 已讓兩模式在 MCP App／headless MCP／TUI 共用路徑＋命中段落的選擇機制；專用聊天平台匯入格式及權限仍未定義，不宣稱能直接讀帳號。

預設對話不自動載入整庫；人選上下文是產品功能。embedding 僅在同義詞與關鍵字落差成為主要問題後評估。公司不能外傳時，保持本機或使用已允許的通道，不能因使用者勾選就假設外傳已核准。

## 作品集加值

保留問題、職場限制、取捨、可跑示範、測試／實測證據及反思。AI 功能不是作品集的先決條件，產品日常可用與公司環境可跑優先。

M12（0.15.0）已補定期校正與離線恢復；M13（0.16.0）已補跨程序寫入協調。本機 116 項測試通過、1 項 Windows cmd 略過；Windows 日常使用的成功標準仍待集中驗收，不以持續擴充功能替代。

## 操作介面方向

使用者已確認需要比零散 CLI 命令更容易操作的介面。0.32.0 已交付類似 Claude Code 的本機終端互動介面；0.34.0 再加入相容 Host 內的 MCP App 搜尋／勾選／送入上下文。兩者沿用既有 Node.js 程式、索引與安全邊界，不開網路連接埠。

目前滑鼠式人工選取已由 MCP App 滿足。只有 Host 不支援嵌入 UI且 TUI 也不能解決長片段／多欄預覽時，才另案增加只綁定 `127.0.0.1`、帶隨機 token、預設不對外連線的本機 Web UI。不得使用雲端網站讀取公司索引。建議與比較見 `docs/UI-DIRECTION.md`。
