## 瀏覽器

獨立資料目錄（`LOCALDOCSEARCH_DATA_DIR`，位於未追蹤的 `.claude/ui-check/data`）與 10 份範例文字檔，`ui --no-open` 啟動，無介面 Chrome 以 DevTools Protocol 操作設定對話框並截圖。審查者親自檢視了後三張（開啟後健康摘要 1440×900 與 1180×800、套用新參數）；「關閉」那張依實作者的描述記錄。

| 視窗 | 情境 | 觀察 |
|---|---|---|
| 1440×900 | 背景自動更新關閉 | 狀態「背景自動更新未執行。」；參數欄位 1.5 秒／6 小時；登入啟動未勾選。 |
| 1440×900 | 開啟後按「重新整理」 | 健康摘要顯示「完整校正 · 已就緒」、待處理 0、完整同步時間與下次校正時間、目前參數 1.5 秒／6 小時。 |
| 1180×800 | 同上 | 摘要、欄位與「完成」按鈕完整可見，無截斷或重疊。 |
| 1440×900 | 套用 3 秒／1 小時 | 狀態列「背景自動更新已依新設定重新啟動。」；標籤動態顯示「每 1 小時完整校正」；摘要參數 3 秒／1 小時；剛重啟時待處理 1 為暫時狀態。 |

- 結束時已停止獨立資料目錄的背景自動更新並關閉工作台與測試用 Chrome；未觸碰使用者的正式資料目錄與其執行中的背景更新。
