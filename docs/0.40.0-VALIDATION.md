## 瀏覽器實測

獨立資料目錄（`LOCALDOCSEARCH_DATA_DIR`）與 10 份範例文件，`ui --no-open` 啟動，無介面 Chrome 以 DevTools Protocol 操作：輸入「自動更新」、按搜尋、截圖。

- 1440×900、1180×800：每筆為檔名、路徑列、片段、兩個小連結；片段兩行內，關鍵字標黃。
- 實測時發現並修正：
  - 路徑列顯示完整根目錄路徑，較長時把「子資料夾 › 檔名」截掉；改為根目錄只顯示最後一段名稱。第一次修改時產生的正規表示式跳脫層數錯誤（只切 `/`），以抽出頁面腳本檢查後修正。
  - 以檔名命中為代表的結果原本寫「僅檔名符合」，但範例 `自動更新測試.txt` 的內文也有命中；改為「檔名符合」。
- 點擊（攔截 `/api/document-action`，不真的開檔）：點標題送 `open`、點「顯示所在位置」送 `reveal`，都帶該筆的 reference；點「加入上下文」後連結變為「移出上下文」、該列標為已選、計數「已選 1 / 20」；頁面沒有明細頁。
