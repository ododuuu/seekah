- 遷移時間：2,089 s（約 35 分鐘；第一次、較小批次的試跑為 2,301 s）。可中斷，接續時跳過已有 marker 的文件。

## 寫入成本

同一份合成語料（1,500 份文件：每份 2,000 格的試算表型、每份 400 行的文字型、單 block 小文件各三分之一），以 `IndexStore.upsert` 逐份寫入。比較上一個 commit（0.37 路徑）與 0.38.0，兩次輪流量測：

| | 總時間 | DB 大小 | 文字型 median | 試算表型 median | 小文件 median |
|---|---:|---:|---:|---:|---:|
| 0.37 | 94–100 s | 151 MiB | 58–64 ms | 120–128 ms | 11–12 ms |
| 0.38.0 | 172–174 s | 256 MiB | 99–105 ms | 196–203 ms | 18–23 ms |

只量索引寫入、不含 parser；完整同步時 parser 與檔案讀取也佔時間，因此整體索引時間的增幅會小於 1.7 倍。
