# 0.48.0 驗證

更新：2026-10-02。package 與 lockfile 版本為 `0.48.0`。

本文件記錄 0.48.0 的合併範圍、已知證據與驗證結果。監工已在合併後的 `main`（`994c920`）實跑 build、`npm test`、UI smoke 與 search-diff；以下結果已回填，不把未執行結果寫成通過。

## 版本與範圍

- 產品規格最高編號：SPEC §100；設計決策最高編號：D136；測試檔最高編號：`m96.test.ts`。上述最高值以本 worktree 的實際檔案／標題查證，不代表本版每一項都新增編號。
- 0.48.0 的行為範圍為 SPEC §§94–100、D127–D136；仍遵守本機處理、LocalDocSearch 資料目錄與 `LOCALDOCSEARCH_DATA_DIR`、既有 IPC／MCP／`docsearch` 相容入口。
- 本次 release 只更新 package 版本與文件；沒有修改 `src/` 或 `test/`。

## 已合併內容

### 文件庫：`feat/library-48`

- 對應 SPEC §§95–97、D127–D129。
- 工作台與 MCP 共用本機 `library.sqlite` metadata 層，提供「最近」、「已釘選」、「分類」與「已存搜尋」。
- 保存路徑、stable reference、名稱、時間／事件與搜尋條件；不保存文件正文、snippet、passage、對話或 AI 輸出。
- 以 transaction、路徑去重、上限、損壞隔離與 loopback token／Origin 邊界維持相容性；聚焦測試為 `m91`–`m93`。

### Codex session：`feat/codex-session-48`

- 對應 SPEC §§98–99、D130–D134；聚焦測試為 `m94`–`m95`。
- 唯讀解析本機 Codex `sessions/` 下的 `rollout-*.jsonl`，產生 session metadata、事件統計與 Reference Set；不把對話、prompt、reasoning、tool result 或附件內容公開，也不把 Codex 變成索引來源。
- Reference Set 只接受明確的絕對路徑與規格化來源分類；list 不做 path existence I/O，detail 才以有界非同步檢查回報存在／未知狀態。
- Codex rollout 格式未公開，解析器依目前欄位與事件形狀實作；Codex 更新可能改變格式，需重新驗證。

### 工作台上下文與結果操作：`feat/ui-context-48`

- 對應 SPEC §94／D136 與 SPEC §100／D135；相關聚焦測試為 `m90`、`m96`。
- 結果列表與表格共用精簡操作列；表格其餘操作收進「更多」選單，寬畫面可延展，避免操作互相覆蓋。
- 右側上下文欄只顯示可辨識的絕對路徑；工作台與 Codex 頁使用同一個 token session 的索引文件集合。
- Codex 頁對已索引且有 stable reference 的 reference 提供「加入上下文／移出上下文」；低信心、未索引、未知或不存在的 reference 不提供此操作。狀態只存在 Workbench 程序記憶體，關閉 Workbench 即清除。

### 使用手冊

`docs/USER-GUIDE.md` 已合併文件庫與 Codex session 使用說明，並與 0.48 的跨頁上下文操作一致；兩個文件手冊分支的內容均納入本版交接文件。

## 相容性與限制

- 不改主索引 schema、文件 id、搜尋語意、排序、根目錄規則、既有資料目錄、IPC／MCP／`docsearch` 識別；文件庫另用獨立 `library.sqlite`。
- Codex 解析只在本機唯讀 rollout；不讀取 history、attachments、認證或 SQLite 狀態，不送出 Codex 內容，不提供執行、修改或附件開啟功能。
- 本版尚未取得公司 Windows 驗收；目前正式公司 Windows 證據仍只到 0.44，不能宣稱 0.45–0.48 已通過。
- 合併後 `main`（`994c920`）的 `npm run build`、`npm test`、UI smoke、search-diff 結果均已回填；公司 Windows 驗收仍另行計算，目前正式證據只到 0.44。
